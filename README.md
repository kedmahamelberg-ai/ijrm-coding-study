# IJRM Coding Study

A browser-based coding environment for a structured study of AI-related social-media content.

## Contribution

The repository turns an interpretive coding design into a repeatable workflow: participant identification, session-based annotation, local saving and export of research records.

**AI as a research phenomenon:** it examines how AI is discussed in everyday public communication, with attention to human experiences and the roles attributed to AI.

**AI as methodology:** rigorous human coding produces inspectable data that can ground, test or qualify computational analysis.

**Teaching and impact:** the app demonstrates how qualitative judgment can be documented in digital research. It can support teaching in content analysis, marketing and communication research, and responsible AI assessment.

The repository contains the study interface and three coding sessions.
